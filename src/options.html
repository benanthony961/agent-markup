Categories

One per line, as id: Label. The first is the default for new notes and highlights. The id is what agents see in exports.

Sites your agent can read from

One origin per line. On these sites, a script on the page can read (never change) your markup, which lets an agent that drives the browser collect it without copy and paste. * matches any port or subdomain, e.g. http://localhost:*. Only add sites you control.
